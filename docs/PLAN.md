# 下一步：先取得可解释、可重复的准入

1. **完整回放初始准入。** 使用冻结的 NSS33 时间样本，逐步统计 guard 检查、分类读取、来源年龄、选定流存在性以及退出原因。不要用缺失数据补造当时的事件。
2. **核查失败是否可重试。** 分类数据刚好更新、来源尚不够新可以等待；实例、class、mark、NAT、owner 或 guardian 不匹配应明确终止，避免用泛化“时间不足”掩盖原因。
3. **离线覆盖整个 A/B/A2 生命周期。** 包含启动、等待、重新取样、续租、改类、过期、撤销和回退；把边界时序与错误传播纳入回放。只有必要时修改一个明确变量。
4. **准备完毕后集中做一次真人单 WAN 测试。** 自动 bulk TCP 与获准 RT UDP、完整 mark 相等、同 NAT/WAN、checkpoint 和独立回滚。先确认进入正确 leaf，再评价同负载 softirq/time_squeeze/吞吐和游戏指标。
5. 真人闭环通过后，才讨论第二 WAN 与共享预算。

不要求用户现在维持游戏或下载。若没有真实连接对，继续离线检查，不制造“真人验收通过”的结论。

每轮结束记录：假设、源文件哈希、变更、负载、ECM/leaf 状态、出口/mark/NAT、CPU/softirq/time_squeeze、吞吐、游戏指标来源、回滚结果、未证明事项。

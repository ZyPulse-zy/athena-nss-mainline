# 下一步：先解决分类器可靠性与发布等待，再集中真人验收

唯一主线：自动游戏分类 → NSS bulk/RT leaf → 真人 CS2＋Steam 单 WAN。

NSS41 功能路径成立，原控制器失败保留。NSS42 后处理/恢复用途/依赖绑定不再重复。NSS44 写前拒绝和首次恢复失败保持。NSS45 两项修复已分别完成短时试装与独立到期恢复，现网仍为 NSS39；软件过期候选只有局部与规则日志算法模拟、尚无完整 apply 子进程/服务故障证明。准备期间不占用用户真人窗口。NSS43 负载观测、20 Mbps 预算和原 TTL 不变。

1. **每次先核验现网。** 常驻仍 `work/nss39/deployment-latest.json`，102 项 NSS42 入口保持原样。检查当前哈希、实际 worker/guardian、生产队列、保护配置和 ECM 全零。NSS45 最终 last-error 属于受控期限退出，NSS44 自然失败及 NSS45 开场三次此前自然溢出各自保持；不能把不同错误混为一谈。新轮次不覆盖 53 份冻结源码或两次恢复证明。
2. **先解决发布与恢复可靠性。** NSS45 行数/局部过期/日志算法案例及轻载试装不再机械重复。补真实 apply 子进程的序列化、producer/实例与锁绑定、成功回收和未知错误拒绝，以及源过期后的完整服务恢复；不能把局部回放计为这些证明。分别核验 restart/crash、换端口/旧流退出和已加速 flow 精确撤销后重学。保留 2048 行、524288 字节、原 6 秒/9 秒期限与 fail-closed，不延长 TTL。每次一个主要变量、新 checkpoint 和独立回滚，风险不能覆盖时留在隔离验证。NSS44 classification 提示随后原完整审核的候选继续按原门槛资格核验，再绑定新入口。33 ms 校验优化不作根本修复。
3. **先确定可解释的负载。** 当前 gate 固定一条 TCP＋一条 UDP，NSS 子组上限 20 Mbps。NSS41 bulk/RT 仅占 B＋撤销 leaf 计数约 4%，总流量和 WAN1 负载又持续上升。NSS43 48 秒、13 个样本已完成这项观测：各 WAN 最高全窗单 TCP 约 16–23 Mbps，WAN5 候选轮换，固定需求 20→30 Mbps 仅增加至多约 1.08 个百分点的整机参考份额。不要重复要求用户挂机来准备同一观察；在下一次真人窗记录同一 WAN、总 LAN4、pps、受控 bulk 活跃性和流量份额，不把 global busy 的小变化当收益。若该子组不足以回答问题，应单独准备并资格核验一个单 WAN 变量；不能在当前 102 项入口中偷偷扩大预算、流数或 TTL。新预算还需考虑该 WAN 的非受控软件流，不能先假定总下行受控。
4. **资格核验完成后只集中请求一次真人窗口。** 用户无需常驻游戏或反复下载；没有真人 flow 时可做离线/只读工作，但不能冒充 CS2 验收。新鲜应用 socket、CT ID/zone/双向元组、完整 mark、NAT 与 WAN 匹配，完整审核通过后，才创建本轮 checkpoint 并先确认独立 owner。
5. **运行新轮次资格核验后的完整验收入口。** 默认拒绝、精确放行、learning 前 tag、精确撤销、相同队列预算和观察循环。候选必须先完成新的绑定和差分/恢复检查；NSS44 只读核验不构成准入。学习前使用 `prewrite` 模式；关闭 ECM 后使用 `recovery` 模式的原完整审核。初始 <1 秒、预学习 <2 秒、原持锁 <6/<9 秒、调度内 5/外 6 秒、owner 45 秒均不变。调度失败保留当前逐帧年龄和读取阶段，不延长期限碰运气。
6. **判断有效性再判断收益。** 确认加速数 0→2→0、bulk/RT leaf 流量、完整 mark/NAT/WAN affinity 保持，完整控制器成功与独立恢复结果另记。NSS43 新增脱敏计数分析与 10% 观测跨度条件；观测相近仍不能证明 offered load 相同。负载未匹配则只记录功能和测量，不能给 CPU 因果结论。游戏和功能可分别评估；单 TCP 占整机少量流量时，不以 global busy 未下降否定加速路径。重点看 softirq/time_squeeze、pps/吞吐、游戏 jitter/loss/Miss/体感；无客户端指标明确未测，RT leaf 丢弃不是端到端 loss。用路由器 uptime 校准游戏窗口，不错配时间。
7. **闭环全部通过后才扩展。** 第二 WAN、共享预算、Wi-Fi、autorate、五 WAN 继续等待。CAKE 是软件对照与未加速流 fallback，不转回长期 CAKE 优化；host fairness 和 N100 不作为方向。

每次生产写入仍需本次 checkpoint 和独立于控制连接的自动回滚。不得刷机/升级内核/改分区/全清 conntrack/重建全部生产 qdisc，保护认证/PBR/sing-box/Tailscale。无上游提交；旧后处理问题保留在 [校验缺陷记录](ISSUE_ECM_WAN_VALIDATOR.md)。
